# SmolLM Station Chat

Минимальная веб-панель для общения с SmolLM2, запущенной на Яндекс Станции.
Вычисления выполняются на колонке; Python-сервер на домашнем компьютере отдаёт
страницу и проксирует потоковый ответ модели, чтобы браузеру не требовался CORS.

## Запуск

Запустите прокси на компьютере, который видит llama.cpp API:

```sh
python3 server.py --bind 0.0.0.0 --port 8090 --upstream http://STATION_IP:8080
```

Замените `STATION_IP` на адрес Станции и откройте `http://SERVER_IP:8090` с
устройства в той же сети. По умолчанию сервер слушает только `127.0.0.1`;
используйте LAN-адрес или `0.0.0.0`, если нужен доступ с других устройств.
Не публикуйте этот порт в интернет: в панели нет аутентификации.

Страница показывает состояние связи, выводит токены по мере генерации, хранит
недавнюю историю только в памяти вкладки, позволяет остановить ответ и начать
новый диалог. История ограничивается последними восемью сообщениями из-за
маленького контекста модели.

Модель имеет всего 135 млн параметров и ориентирована прежде всего на английский.
Панель не меняет её возможностей: ответы по-русски могут быть слабыми.
